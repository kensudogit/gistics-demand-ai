# 要件定義チェックリスト

## 業務
- 需要予測: 粒度（SKU×倉庫×日など）、対象期間、予測ホライズン、欠品時の観測バイアス、販促/祝日、返品
- 配送: デポ、配送先、車両台数/容量、時間窓、休憩、積卸時間、交通規制、ドライバー勤務、複数デポ
- 入力: 配送実績、注文、在庫、天気予報、交通、祝日、位置情報。権利と更新頻度を確認
- 出力: 予測値・区間・根拠、最適ルート・距離・所要時間・未配送・制約違反

## 非機能と受入条件
- API p95目標、バッチ終了時刻、データ遅延、日次件数、同時利用、月額予算を定義
- モデル評価: WAPE/MAE、需要ゼロ時の指標、商品/拠点ごとの分解、既存手法との差
- ルート評価: 実行可能性100%を前提に、距離/時間/遅延/車両台数/計算時間を比較
- 障害: データ欠損時のフォールバック、再実行、冪等性、アラート、手動運用
- 個人情報: 住所・配送先・位置情報の取り扱い、保存期間、マスキング

## 成果物
業務フロー、データ辞書、API OpenAPI、ER/分析スキーマ、モデルカード、テスト仕様、運用Runbook。
